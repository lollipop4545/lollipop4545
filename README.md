### 🚀 About Me

I bridge the gap between low-level hardware, Linux kernel internals, and modern software systems. My work spans custom Android kernel bring-up and containerized ARM64 infrastructure to building production web applications and Zero Trust networks.

- 🎓 **Studying:** Electronic & Telecommunication Engineering at King Mongkut's University of Technology Thonburi (KMUTT).
- 🌱 **Maintaining:** **Limea Kernel**, custom Android Linux kernels with native Docker support for [Redmi Note 8/8T](https://github.com/lollipop4545/Limea_Kernel-Ginkgo) and [Infinix Note 10 Pro / X695D](https://github.com/lollipop4545/Limea_Kernel-X695D) (experimental).
- ⚡ **Exploring:** Clean-room driver bring-up, Device Tree (DTS/DTB), Android bootloaders (AVB2/Fastboot/GSI), and embedded systems.
- 🌐 **Deploying:** Containerized services via Docker on ARM64 devices and Linux/Azure VMs, fronted securely with Cloudflare Tunnels (Zero Trust).
- 🛠️ **Building:** Control panels and production web apps using Next.js (App Router), TypeScript, and Tailwind CSS.
